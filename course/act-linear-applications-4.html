    Worksheet Activity: Modeling with Linear Functions
    

    A linear function can be written as \(y = mx + b\text{,}\) where \(m\) is the slope (rate of change) and \(b\) is the \(y\)-intercept (starting value). If you know the rate of change and one value of the function, you can substitute and solve for whichever piece is missing.
    🔗

    1. Example.

    A tree is currently 4 feet tall and grows 1.5 feet per year. Write a linear equation for the height \(h\) of the tree after \(t\) years.
    🔗
    Slope (rate of change): \(m = 1.5\text{.}\) Starting value (\(y\)-intercept): \(b = 4\text{.}\) Equation: \(h = 1.5t + 4\text{.}\)
    🔗
    🔗

    2.

    A streaming service starts you off with a $25 gift card balance, and each song purchase costs $3. Write a linear equation for your remaining balance \(B\) after purchasing \(n\) songs.
    🔗
    Slope: \(\quad\) \(y\)-intercept: \(\quad\) Equation:
    🔗
    Follow-up: How many total songs can you buy using the gift card?
    🔗
    Answer.
    Slope: \(m = -3\text{;}\) \(y\)-intercept: \(b = 25\text{;}\) Equation: \(B = -3n + 25\text{.}\) Follow-up: Set \(B = 0\) and solve to get \(n = 25/3 \approx 8.3\text{,}\) so you can buy 8 songs.
    🔗
    🔗
    🔗

    3.

    A plumber charges a $60 service call fee plus $45 per hour of labor. Write a linear equation for the total cost \(C\) after \(h\) hours of work.
    🔗
    Slope: \(\quad\) \(y\)-intercept: \(\quad\) Equation:
    🔗
    Follow-up: How much will three hours of work cost?
    🔗
    Answer.
    Slope: \(m = 45\text{;}\) \(y\)-intercept: \(b = 60\text{;}\) Equation: \(C = 45h + 60\text{.}\) Follow-up: \(C = 45(3) + 60 = 195\text{,}\) so three hours costs $195.
    🔗
    🔗
    🔗

    4.

    A person opens a new savings account and deposits $125 per month. After 4 months, there is $900 in the account. Write a linear equation for the balance \(B\) after \(x\) months.
    🔗
    Hint: Use the rate of change and the known value to solve for the \(y\)-intercept first.
    🔗
    Slope: \(\quad\) \(y\)-intercept: \(\quad\) Equation:
    🔗
    Follow-up: How long will it take to save up $1500?
    🔗
    Answer.
    Slope: \(m = 125\text{.}\) Substituting the known point \((4, 900)\text{:}\) \(900 = 125(4) + b\text{,}\) so \(b = 400\text{.}\) Equation: \(B = 125x + 400\text{.}\) Follow-up: Set \(B = 1500\) and solve to get \(x = 8.8\text{,}\) so it takes about 9 full months.
    🔗
    🔗
    🔗

    5. Example.

    A candle is 8 inches tall after burning for 2 hours, and 5 inches tall after burning for 6 hours. Write a linear equation for the height \(h\) of the candle after \(t\) hours.
    🔗
    Step 1: Find the slope using both points \((2, 8)\) and \((6, 5)\text{:}\)
    \begin{equation*} m = \frac{5 - 8}{6 - 2} = \frac{-3}{4} = -0.75 \end{equation*}
    🔗
    Step 2: Substitute one point and the slope into \(y = mx + b\) to solve for \(b\text{.}\) Using \((2, 8)\text{:}\)
    \begin{equation*} 8 = (-0.75)(2) + b \quad \Rightarrow \quad 8 = -1.5 + b \quad \Rightarrow \quad b = 9.5 \end{equation*}
    🔗
    Equation: \(h = -0.75t + 9.5\text{.}\)
    🔗
    🔗

    6. Car Value.

    A car’s value was $18,000 after 1 year of ownership and $14,400 after 3 years of ownership. Write a linear equation for the car’s value \(V\) after \(t\) years.
    🔗
    (a)
    Step 1: Find the slope using both points.
    🔗
    Answer.
    \(m = \dfrac{14400 - 18000}{3 - 1} = \dfrac{-3600}{2} = -1800\)
    🔗
    🔗
    🔗
    (b)
    Step 2: Substitute one point and the slope to solve for \(b\text{.}\)
    🔗
    Answer.
    Using \((1, 18000)\text{:}\) \(18000 = -1800(1) + b\text{,}\) so \(b = 19800\text{.}\)
    🔗
    🔗
    🔗
    (c)
    Write the equation:
    🔗
    Answer.
    \(V = -1800t + 19800\)
    🔗
    🔗
    🔗
    🔗

    7. Gym Membership.

    A gym had 220 members after 3 months and 340 members after 8 months. Write a linear equation for the number of members \(M\) after \(t\) months.
    🔗
    (a)
    Step 1: Find the slope using both points.
    🔗
    Answer.
    \(m = \dfrac{340 - 220}{8 - 3} = \dfrac{120}{5} = 24\)
    🔗
    🔗
    🔗
    (b)
    Step 2: Substitute one point and the slope to solve for \(b\text{.}\)
    🔗
    Answer.
    Using \((3, 220)\text{:}\) \(220 = 24(3) + b\text{,}\) so \(b = 148\text{.}\)
    🔗
    🔗
    🔗
    (c)
    Write the equation:
    🔗
    Answer.
    \(M = 24t + 148\)
    🔗

    Worksheet Activity: Modeling with Linear Functions II
    

    A linear function can be written as \(y = mx + b\text{,}\) where \(m\) is the slope (rate of change) and \(b\) is the \(y\)-intercept (starting value). If you know the rate of change and one value of the function, you can substitute and solve for whichever piece is missing.
    🔗
    Pay attention to the sign of the slope. If a quantity is increasing, the slope is positive. If a quantity is decreasing, the slope is negative.
    🔗

    1. Example.

    A student has $200 in their dining account and spends about $25 per week. Write a linear equation for the remaining balance \(B\) after \(w\) weeks.
    🔗
    Slope (rate of change): \(m = -25\) (negative because the balance is decreasing). Starting value (\(y\)-intercept): \(b = 200\text{.}\) Equation: \(B = -25w + 200\text{.}\)
    🔗
    🔗

    2.

    Your phone plan comes with 15 GB of data for the month, and you use about 2.5 GB per week. Write a linear equation for your remaining data \(D\) (in GB) after \(w\) weeks.
    🔗
    Slope: \(\quad\) \(y\)-intercept: \(\quad\) Equation:
    🔗
    Follow-up: After how many weeks will your data run out?
    🔗
    Answer.
    Slope: \(m = -2.5\text{;}\) \(y\)-intercept: \(b = 15\text{;}\) Equation: \(D = -2.5w + 15\text{.}\) Follow-up: Set \(D = 0\) and solve to get \(w = 6\text{,}\) so the data runs out after 6 weeks.
    🔗
    🔗
    🔗

    3.

    A campus coffee shop has a loyalty program. You currently have 50 points, and you earn 15 points for every visit. Write a linear equation for your total points \(P\) after \(v\) visits.
    🔗
    Slope: \(\quad\) \(y\)-intercept: \(\quad\) Equation:
    🔗
    Follow-up: A free drink requires 200 points. How many more visits do you need?
    🔗
    Answer.
    Slope: \(m = 15\text{;}\) \(y\)-intercept: \(b = 50\text{;}\) Equation: \(P = 15v + 50\text{.}\) Follow-up: Set \(P = 200\) and solve to get \(v = 10\text{,}\) so you need 10 more visits.
    🔗
    🔗
    🔗

    4. Example.

    A student worked 3 hours at their campus job and had earned $33.75 total. After 7 hours they had earned $78.75 total. Write a linear equation for total earnings \(E\) after \(h\) hours.
    🔗
    Step 1: Find the slope using both points \((3, 33.75)\) and \((7, 78.75)\text{:}\)
    \begin{equation*} m = \frac{78.75 - 33.75}{7 - 3} = \frac{45}{4} = 11.25 \end{equation*}
    🔗
    Step 2: Substitute one point and the slope into \(y = mx + b\) to solve for \(b\text{.}\) Using \((3, 33.75)\text{:}\)
    \begin{equation*} 33.75 = (11.25)(3) + b \quad \Rightarrow \quad 33.75 = 33.75 + b \quad \Rightarrow \quad b = 0 \end{equation*}
    🔗
    Equation: \(E = 11.25h\text{.}\) The \(y\)-intercept of 0 means no hours worked, no pay earned.
    🔗
    🔗

    5. Tuition Costs.

    A student has been tracking their total college tuition costs. After 2 semesters they had spent $4,200 total, and after 5 semesters they had spent $9,600 total. Write a linear equation for total tuition cost \(C\) after \(s\) semesters.
    🔗
    (a)
    Step 1: Find the slope using both points.
    🔗
    Answer.
    \(m = \dfrac{9600 - 4200}{5 - 2} = \dfrac{5400}{3} = 1800\)
    🔗
    🔗
    🔗
    (b)
    Step 2: Substitute one point and the slope to solve for \(b\text{.}\)
    🔗
    Answer.
    Using \((2, 4200)\text{:}\) \(4200 = 1800(2) + b\text{,}\) so \(b = 600\text{.}\)
    🔗
    🔗
    🔗
    (c)
    Write the equation:
    🔗
    Answer.
    \(C = 1800s + 600\)
    🔗
    🔗
    🔗
    (d)
    What does the \(y\)-intercept represent in this context?
    🔗
    Answer.
    The \(y\)-intercept of $600 represents an initial cost paid before any semesters of classes begin (for example, an enrollment or registration fee).
    🔗
    🔗
    🔗
    🔗

    6. Apartment Complex.

    An off-campus apartment complex had 140 units rented after 3 months of opening and 220 units rented after 7 months. Write a linear equation for the number of rented units \(U\) after \(t\) months.
    🔗
    (a)
    Step 1: Find the slope using both points.
    🔗
    Answer.
    \(m = \dfrac{220 - 140}{7 - 3} = \dfrac{80}{4} = 20\)
    🔗
    🔗
    🔗
    (b)
    Step 2: Substitute one point and the slope to solve for \(b\text{.}\)
    🔗
    Answer.
    Using \((3, 140)\text{:}\) \(140 = 20(3) + b\text{,}\) so \(b = 80\text{.}\)
    🔗
    🔗
    🔗
    (c)
    Write the equation:
    🔗
    Answer.
    \(U = 20t + 80\)
    🔗
    🔗
    🔗
    (d)
    The complex has 300 total units. At this rate, when will it be fully rented?
    🔗
    Answer.
    Set \(U = 300\) and solve: \(300 = 20t + 80\text{,}\) so \(t = 11\text{.}\) The complex will be fully rented after 11 months.
