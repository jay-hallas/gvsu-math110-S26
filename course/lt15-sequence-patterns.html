    Worksheet Learning Target 15: Identifying Patterns in Sequences and Data
    

    Objectives

    • Given a mathematical sequence of data, I can determine if it fits a linear, exponential, or quadratic pattern and explain what characteristics support my conclusion.
      🔗
    🔗

    1. Pattern 1: Tripling Columns.

    Case 0 is a single column of 4 squares. In each new case, the number of columns triples.
    🔗
    
    Four cases of square tiles arranged in columns of four. Case 0 is one column, a total of four squares. Case 1 is three columns, a total of twelve squares. Case 2 is nine columns, a total of thirty-six squares. Cases 3 and 4 are shown as empty outlines for students to fill in.
    🔗

    (a)

    Complete the table of square counts for \(n = 0\) through \(4\text{.}\)
    🔗
    \(n\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(4\) \(12\) \(36\)
    Answer.
    The counts are \(4, 12, 36, 108, 324\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Determine whether the pattern is linear, exponential, quadratic, or neither. Explain how you know, and find an equation for \(y\) in terms of \(n\text{.}\)
    🔗
    Answer.
    It is exponential. The ratios between consecutive outputs are constant: \(12/4 = 3\text{,}\) \(36/12 = 3\text{,}\) and \(108/36 = 3\text{.}\) The first differences are \(8, 24, 72\text{,}\) which are not constant, so it is not linear, and the second differences are \(16, 48\text{,}\) which are not constant either, so it is not quadratic. Since the growth factor is \(3\) and the value at \(n = 0\) is \(4\text{,}\) the equation is \(y = 4(3)^n\text{.}\)
    🔗
    🔗
    🔗
    🔗

    2. Pattern 2: Growing Rectangle.

    Case 1 is a rectangle that is 6 blocks wide and 4 blocks tall. Each new case grows by one block in both width and height.
    🔗
    
    A sequence of rectangles built from square blocks. Case 1 is six blocks wide and four blocks tall. Case 2 is seven by five. Case 3 is eight by six. Case 4 is shown as an empty outline nine blocks wide and seven blocks tall.
    🔗

    (a)

    Complete the table of block counts for \(n = 0\) through \(5\text{,}\) where Case 0 represents the base dimensions 5 by 3.
    🔗
    \(n\) \(0\) \(1\) \(2\) \(3\) \(4\) \(5\)
    \(y\) \(15\) \(24\) \(35\) \(48\)
    Answer.
    The counts are \(15, 24, 35, 48, 63, 80\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Determine whether the pattern is linear, exponential, quadratic, or neither. Explain your reasoning and find an equation for \(y\) in terms of \(n\text{.}\)
    🔗
    Answer.
    It is quadratic. The first differences are \(9, 11, 13, 15, 17\text{,}\) which are not constant, so it is not linear. The second differences are \(2, 2, 2, 2\text{,}\) which are constant.
    🔗
    Since the \(n\)-values step by \(1\text{,}\) the leading coefficient is half the second difference, so \(a = 1\text{.}\) The value at \(n = 0\) gives \(c = 15\text{.}\) Substituting \(n = 1, y = 24\) gives \(1 + b + 15 = 24\text{,}\) so \(b = 8\text{.}\) The equation is \(y = n^2 + 8n + 15\text{,}\) which factors as \(y = (n+5)(n+3)\text{.}\) That factored form is exactly the dimensions of the rectangle, since Case \(n\) is \((n+5)\) blocks wide and \((n+3)\) blocks tall.
    🔗
    🔗
    🔗
    🔗

    3. Pattern 3: Repeating Column.

    Each case shows a column with three possible positions for a circle. The dashed outlines mark positions where no circle appears in that case. Six cases are shown below, which is enough to see the pattern repeat twice.
    🔗
    
    Eight columns, each with three positions for a circle. Case 1 has the bottom two positions filled. Case 2 has all three filled. Case 3 has only the bottom filled. Cases 4, 5, and 6 repeat that same arrangement in the same order. Cases 7 and 8 are shown as empty outlines for students to fill in.
    🔗

    (a)

    Count the circles in Cases 4, 5, and 6 from the figure, then extend the pattern to fill in Cases 7 and 8.
    🔗
    \(n\) \(1\) \(2\) \(3\) \(4\) \(5\) \(6\) \(7\) \(8\)
    \(y\) \(2\) \(3\) \(1\)
    Answer.
    The counts are \(2, 3, 1, 2, 3, 1, 2, 3\text{.}\) The block of three values repeats, so the count depends only on where \(n\) falls in the cycle of three.
    🔗
    🔗
    🔗

    (b)

    Determine whether this pattern is linear, exponential, quadratic, or neither. Explain your reasoning.
    🔗
    Answer.
    It is neither. The first differences are \(1, -2, 1, 1, -2, 1, 1\text{,}\) which are not constant, so it is not linear. The second differences are \(-3, 3, 0, -3, 3, 0\text{,}\) which are not constant, so it is not quadratic. The ratios are \(1.5, 0.33, 2, 1.5, 0.33, 2, 1.5\text{,}\) which are not constant, so it is not exponential.
    🔗
    Notice that the differences and the ratios repeat in blocks of three, just like the counts do. The values cycle rather than growing or decaying, so none of the three families describes them. This is a good reminder that a sequence can have a clear, predictable rule and still not be linear, exponential, or quadratic.
    🔗
    🔗
    🔗

    (c)

    Predict the number of circles in Case 20 and explain how you decided without drawing all twenty cases.
    🔗
    Answer.
    There will be \(3\) circles. The pattern repeats every \(3\) cases, and Cases 2, 5, 8, 11, 14, 17, and 20 all sit in the same position within the cycle, each having \(3\) circles. Another way to say it: dividing \(20\) by \(3\) leaves a remainder of \(2\text{,}\) and every case whose remainder is \(2\) has \(3\) circles.
    🔗
    🔗
    🔗
    🔗

    4. Pattern 4: Growing X-Shape.

    An X is built from square tiles. Case 1 uses 5 tiles: one center tile with a single tile extending diagonally in each of the four directions. Each new case extends every arm of the X by one more tile.
    🔗
    
    Three X shapes built from square tiles arranged along two crossing diagonals. Case 1 has a center tile with one tile out each diagonal, five tiles in all. Case 2 has arms two tiles long, nine tiles in all. Case 3 has arms three tiles long, thirteen tiles in all. Case 4 is shown as an empty square outline nine tiles across.
    🔗

    (a)

    Complete the table of tile counts for \(n = 1\) through \(5\text{.}\)
    🔗
    \(n\) \(1\) \(2\) \(3\) \(4\) \(5\)
    \(y\) \(5\) \(9\) \(13\)
    Answer.
    The counts are \(5, 9, 13, 17, 21\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Determine whether the pattern is linear, exponential, quadratic, or neither. Explain how you know, and find an equation for \(y\) in terms of \(n\text{.}\)
    🔗
    Answer.
    It is linear. The first differences are constant at \(4\text{,}\) since \(9 - 5 = 4\text{,}\) \(13 - 9 = 4\text{,}\) and so on. That matches what happens in the picture: each new case adds one tile to each of the four arms, so exactly \(4\) tiles are added every time.
    🔗
    The slope is \(4\text{.}\) Working backward from Case 1, the value at \(n = 0\) would be \(5 - 4 = 1\text{,}\) which is just the center tile with no arms. So the equation is \(y = 4n + 1\text{.}\) Check at \(n = 3\text{:}\) \(4(3) + 1 = 13\text{,}\) which matches.
    🔗
    The structure of the X explains the equation directly: \(4n\) counts the four arms of length \(n\text{,}\) and the \(+1\) counts the center tile that all four arms share.
    🔗
    🔗
    🔗
    🔗

    5. Tables Practice: Linear, Exponential, Quadratic, or Neither.

    For each table below, determine whether the relationship is linear, exponential, quadratic, or neither. Explain your reasoning and find an equation when applicable.
    🔗

    (a)

    Table A:
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(12\) \(9\) \(6\) \(3\) \(0\)
    Answer.
    Linear. The first differences are constant at \(-3\text{,}\) since \(9 - 12 = -3\text{,}\) \(6 - 9 = -3\text{,}\) and so on. With a slope of \(-3\) and a vertical intercept of \(12\text{,}\) the equation is \(y = -3x + 12\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Table B:
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(80\) \(40\) \(20\) \(10\) \(5\)
    Answer.
    Exponential decay. The ratios between consecutive outputs are constant at \(0.5\text{,}\) since \(40/80 = 0.5\text{,}\) \(20/40 = 0.5\text{,}\) and so on. With an initial value of \(80\text{,}\) the equation is \(y = 80(0.5)^x\text{.}\) Each step keeps half of the previous amount.
    🔗
    🔗
    🔗

    (c)

    Table C:
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(2\) \(5\) \(14\) \(29\) \(50\)
    Answer.
    Quadratic. The first differences are \(3, 9, 15, 21\text{,}\) which are not constant. The second differences are \(6, 6, 6\text{,}\) which are constant.
    🔗
    Since \(2a = 6\text{,}\) we get \(a = 3\text{.}\) The value at \(x = 0\) gives \(c = 2\text{.}\) Substituting \(x = 1, y = 5\) gives \(3 + b + 2 = 5\text{,}\) so \(b = 0\text{.}\) The equation is \(y = 3x^2 + 2\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Table D:
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(1\) \(2\) \(5\) \(14\) \(41\)
    Answer.
    Neither. The first differences are \(1, 3, 9, 27\text{,}\) which are not constant, so it is not linear. The second differences are \(2, 6, 18\text{,}\) which are not constant, so it is not quadratic. The ratios are \(2, 2.5, 2.8, 2.93\text{,}\) which are not constant, so it is not exponential.
    🔗
    There is still a rule at work: each first difference is triple the one before it. The pattern is predictable, it just is not one of the three families we have equations for.
    🔗
    🔗
