    Worksheet Learning Target 12: Quadratic Patterns
    

    Objectives

    • I can recognize and identify key characteristics of a quadratic pattern represented in a table, graph, equation or application.
      🔗
    • I can translate between different representations.
      🔗
    🔗

    1. Pattern 1: Growing Rectangle.

    Case 1 is a rectangle that is 4 blocks wide and 2 blocks tall. Each new case grows by one block in both the width and the height.
    🔗

    (a)

    What type of pattern is this: linear, exponential, quadratic, or none of these? Explain how you know.
    🔗
    Answer.
    It is quadratic. The block counts are \(8, 15, 24, 35\) . The differences between consecutive cases are \(7, 9, 11\) , which are not constant, so the pattern is not linear. The ratios are \(15/8 = 1.875\) and \(24/15 = 1.6\) , which are not constant either, so it is not exponential. The second differences are \(2, 2\) , and a constant second difference is the signature of a quadratic pattern.
    🔗
    🔗
    🔗

    (b)

    Find a formula for the number of blocks \(y\) in case \(n\) .
    🔗
    Answer.
    Case \(n\) is \(n+3\) blocks wide and \(n+1\) blocks tall, so \(y = (n+3)(n+1)\) . Expanding gives \(y = n^2 + 4n + 3\) . Check case \(3\) : \(9 + 12 + 3 = 24\) blocks, which matches the picture.
    🔗
    🔗
    🔗
    🔗

    2. Pattern 2: Staircase.

    Each case adds one more column to the staircase, and each column is one block taller than the one to its left.
    🔗

    (a)

    What type of pattern is this: linear, exponential, quadratic, or none of these? Explain how you know.
    🔗
    Answer.
    It is quadratic. The counts are \(1, 3, 6, 10\) . The first differences are \(2, 3, 4\) , so the pattern is not linear. The ratios \(3, 2, 5/3\) are not constant, so it is not exponential. The second differences are \(1, 1\) , which is constant, so the pattern is quadratic.
    🔗
    🔗
    🔗

    (b)

    Find a formula for the number of blocks \(y\) in case \(n\) .
    🔗
    Answer.
    Case \(n\) is made of columns of height \(1, 2, 3, \dots, n\) , so \(y = 1 + 2 + \cdots + n\) . Two copies of the staircase fit together into an \(n\) by \(n+1\) rectangle, so \(y = \frac{n(n+1)}{2}\) , which expands to \(y = \frac{1}{2}n^2 + \frac{1}{2}n\) . Check case \(4\) : \(\frac{4 \cdot 5}{2} = 10\) blocks.
    🔗
    🔗
    🔗
    🔗

    3. Pattern 3: Two Rows.

    Each case has a top row and a longer bottom row. Both rows grow by one block from case to case.
    🔗

    (a)

    What type of pattern is this: linear, exponential, quadratic, or none of these? Explain how you know.
    🔗
    Answer.
    It is linear. The counts are \(4, 6, 8, 10\) , and the pattern gains exactly \(2\) blocks from each case to the next. A constant first difference means the pattern is linear, and the second differences are all \(0\) , so it is not quadratic.
    🔗
    🔗
    🔗

    (b)

    Find a formula for the number of blocks \(y\) in case \(n\) .
    🔗
    Answer.
    The rate of change is \(2\) blocks per case. Working backward, case \(0\) would have \(2\) blocks, so \(y = 2n + 2\) . Check case \(3\) : \(2(3) + 2 = 8\) blocks.
    🔗
    🔗
    🔗
    🔗

    4. Pattern 4: Doubling Block.

    Each case is two blocks tall, and the width doubles from one case to the next.
    🔗

    (a)

    What type of pattern is this: linear, exponential, quadratic, or none of these? Explain how you know.
    🔗
    Answer.
    It is exponential. The counts are \(2, 4, 8, 16\) . The first differences are \(2, 4, 8\) and the second differences are \(2, 4\) , so it is neither linear nor quadratic. Each case is \(2\) times the one before it, and a constant ratio is the signature of an exponential pattern.
    🔗
    🔗
    🔗

    (b)

    Find a formula for the number of blocks \(y\) in case \(n\) .
    🔗
    Answer.
    The growth factor is \(2\) . Working backward, case \(0\) would have \(1\) block, so \(y = 1 \cdot 2^n = 2^n\) . Check case \(4\) : \(2^4 = 16\) blocks.
    🔗
    🔗
    🔗
    🔗

    5. Table A.

    Consider the values in the table below.
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(3\) \(4\) \(7\) \(12\) \(19\)

    (a)

    What type of pattern is this: linear, exponential, quadratic, or none of these? Explain how you know.
    🔗
    Answer.
    It is quadratic. The first differences are \(1, 3, 5, 7\) , which are not constant, so the table is not linear. The ratios \(4/3\) and \(7/4\) are not constant, so it is not exponential. The second differences are \(2, 2, 2\) , so the table is quadratic.
    🔗
    🔗
    🔗

    (b)

    Find a formula for \(y\) in terms of \(x\) .
    🔗
    Answer.
    For a quadratic \(y = ax^2 + bx + c\) , the constant second difference equals \(2a\) . Here the second difference is \(2\) , so \(a = 1\) . The value at \(x=0\) gives \(c = 3\) . Using \(x=1\) : \(1 + b + 3 = 4\) , so \(b = 0\) . The formula is \(y = x^2 + 3\) . Check \(x=4\) : \(16 + 3 = 19\) .
    🔗
    🔗
    🔗
    🔗

    6. Table B.

    Consider the values in the table below.
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(1\) \(6\) \(15\) \(28\) \(45\)

    (a)

    What type of pattern is this: linear, exponential, quadratic, or none of these? Explain how you know.
    🔗
    Answer.
    It is quadratic. The first differences are \(5, 9, 13, 17\) , so the table is not linear. The ratios \(6\) , \(2.5\) , and \(28/15\) are shrinking, so it is not exponential. The second differences are \(4, 4, 4\) , which is constant, so the table is quadratic.
    🔗
    🔗
    🔗

    (b)

    Find a formula for \(y\) in terms of \(x\) .
    🔗
    Answer.
    The second difference is \(4\) , and the second difference equals \(2a\) , so \(a = 2\) . The value at \(x = 0\) gives \(c = 1\) . Using \(x = 1\) : \(2(1)^2 + b(1) + 1 = 6\) , so \(b = 3\) . The formula is \(y = 2x^2 + 3x + 1\) . Check \(x = 3\) : \(18 + 9 + 1 = 28\) .
    🔗
    🔗
    🔗
    🔗

    7. Table C.

    Consider the values in the table below.
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(5\) \(15\) \(45\) \(135\) \(405\)

    (a)

    What type of pattern is this: linear, exponential, quadratic, or none of these? Explain how you know.
    🔗
    Answer.
    It is exponential. The first differences are \(10, 30, 90, 270\) and the second differences are \(20, 60, 180\) , so the table is neither linear nor quadratic. Every ratio of consecutive outputs is \(3\) , and a constant ratio means the table is exponential.
    🔗
    🔗
    🔗

    (b)

    Find a formula for \(y\) in terms of \(x\) .
    🔗
    Answer.
    The growth factor is \(3\) and the value at \(x = 0\) is \(5\) , so \(y = 5(3)^x\) . Check \(x = 4\) : \(5(81) = 405\) .
    🔗
    🔗
    🔗
    🔗

    8. Table D.

    Consider the values in the table below.
    🔗
    \(x\) \(1\) \(2\) \(3\) \(4\) \(5\)
    \(y\) \(12\) \(6\) \(4\) \(3\) \(2.4\)

    (a)

    What type of pattern is this: linear, exponential, quadratic, or none of these? Explain how you know.
    🔗
    Answer.
    It is none of these. The first differences are \(-6, -2, -1, -0.6\) , so the table is not linear. The second differences are \(4, 1, 0.4\) , so it is not quadratic. The ratios are \(0.5\) , \(0.\overline{6}\) , \(0.75\) , and \(0.8\) , which are not constant, so it is not exponential either. The outputs are decreasing toward zero but never at a constant rate or a constant factor.
    🔗
    🔗
    🔗

    (b)

    Since this table is not one of our three types, describe in words what is happening to the outputs as the inputs increase.
    🔗
    Answer.
    The outputs drop quickly at first and then level off, getting closer and closer to zero without reaching it. Each output is \(12\) divided by the input, so doubling the input cuts the output in half. This kind of relationship is called inversely proportional.
    🔗
    🔗
    🔗
