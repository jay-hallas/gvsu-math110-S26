    1. Matching: Functions and Inverses.

    Below are three graphs. Match each graph to the statement that best describes it by writing the correct Roman numeral (I, II, or III) in the blank.
    🔗
    I. Not a function
    🔗
    II. Is a function, but does not have an inverse function
    🔗
    III. Is a function and has an inverse function
    🔗
    
    Graph A is a V shape with its vertex at the origin. Graph B is a parabola opening to the right with its vertex at the origin. Graph C is an increasing cubic curve passing through the origin.
    🔗

    (a)

    Graph A (the left graph) matches . Briefly explain your choice.
    🔗
    Solution.
    Graph A matches statement II. It passes the vertical line test, so it is a function. However, a horizontal line such as \(y = 2\) crosses it in two places, which means two different inputs share the same output. A function has to pass the horizontal line test to have an inverse function, so this one does not.
    🔗
    🔗
    🔗

    (b)

    Graph B (the middle graph) matches . Briefly explain your choice.
    🔗
    Solution.
    Graph B matches statement I. A vertical line such as \(x = 1\) crosses the curve twice, so a single input is paired with two different outputs. That fails the vertical line test, so this graph is not a function at all.
    🔗
    🔗
    🔗

    (c)

    Graph C (the right graph) matches . Briefly explain your choice.
    🔗
    Solution.
    Graph C matches statement III. The curve is always increasing, so it passes both the vertical line test and the horizontal line test. Every output comes from exactly one input, which means the function has an inverse function.
    🔗
    🔗
    🔗

    2. Sketching the Graph of an Inverse.

    The graph of a function \(f(x)\) is shown below, with three points marked. The dashed line is \(y = x\text{.}\)
    🔗
    
    A coordinate grid running from negative 2 to 7 on both axes. A logarithmic curve rises steeply on the left near the vertical line x equals negative 2 and then flattens as it moves right, passing through the marked points negative 1 comma 1, 0 comma 2, and 2 comma 3. A dashed line representing y equals x runs diagonally across the grid.
    🔗

    (a)

    Identify the coordinates of the three marked points on the graph of \(f(x)\text{.}\) Then state the matching coordinates that must exist on the inverse function \(f^{-1}(x)\text{,}\) and plot those three corresponding points on the grid above.
    🔗
    Solution.
    The three marked points on \(f\) are \((-1, 1)\text{,}\) \((0, 2)\text{,}\) and \((2, 3)\text{.}\)
    🔗
    An inverse function reverses the roles of input and output, so every point \((x, y)\) on \(f\) becomes the point \((y, x)\) on \(f^{-1}\text{.}\) Swapping each pair gives the three points on the inverse:
    🔗
    \((1, -1)\text{,}\) \((2, 0)\text{,}\) and \((3, 2)\text{.}\)
    🔗
    🔗
    🔗

    (b)

    The dashed line represents \(y = x\text{.}\) Use your plotted points and the reflection line to sketch the complete graph of the inverse function \(f^{-1}(x)\) on the same set of axes.
    🔗
    Solution.
    The graph of \(f^{-1}\) is the mirror image of the graph of \(f\) across the dashed line \(y = x\text{.}\) Because \(f\) is a logarithmic curve with a vertical asymptote at \(x = -2\text{,}\) its reflection is an exponential curve with a horizontal asymptote at \(y = -2\text{.}\)
    🔗
    The sketched curve should pass through the three plotted points, rise steeply to the right, and flatten out toward the line \(y = -2\) as it moves to the left. Symbolically the inverse is \(f^{-1}(x) = 2^{x-1} - 2\text{,}\) though the sketch does not require finding this formula.
    🔗
    
    A coordinate grid from negative 2 to 7 on both axes. The function f, drawn in navy, is a logarithmic curve passing through negative 1 comma 1, then 0 comma 2, then 2 comma 3, with a vertical asymptote at x equals negative 2. Its inverse, drawn in red, is an exponential curve passing through 1 comma negative 1, then 2 comma 0, then 3 comma 2, with a horizontal asymptote at y equals negative 2. The two curves are mirror images across the dashed blue line y equals x.
    🔗

    3. Finding an Inverse Algebraically.

    Find the inverse function \(h^{-1}(x)\) for the linear function given by \(h(x) = -\frac{2}{3}x + 4\text{.}\) Show all of your algebraic steps clearly.
    🔗
    Solution.
    Start by replacing \(h(x)\) with \(y\text{.}\)
    🔗
    \begin{align*} y \amp = -\frac{2}{3}x + 4 \end{align*}
    🔗
    Swap the roles of the two variables, since the inverse reverses input and output.
    🔗
    \begin{align*} x \amp = -\frac{2}{3}y + 4 \end{align*}
    🔗
    Subtract \(4\) from both sides to isolate the term containing \(y\text{.}\)
    🔗
    \begin{align*} x - 4 \amp = -\frac{2}{3}y \end{align*}
    🔗
    Multiply both sides by \(-\frac{3}{2}\text{,}\) which is the reciprocal of \(-\frac{2}{3}\text{.}\)
    🔗
    \begin{align*} -\frac{3}{2}(x - 4) \amp = y \end{align*}
    🔗
    So the inverse function is
    🔗
    \begin{gather*} h^{-1}(x) = -\frac{3}{2}(x - 4) = -\frac{3}{2}x + 6 \end{gather*}
    🔗
    A quick check: \(h(3) = -\frac{2}{3}(3) + 4 = 2\text{,}\) and \(h^{-1}(2) = -\frac{3}{2}(2) + 6 = 3\text{.}\) The inverse returns the original input, so the answer is correct.
    🔗
    🔗
    🔗

    4. Solving Equations.

    Solve each of the following equations for \(x\text{.}\) Show your step-by-step algebraic process.
    🔗

    (a)

    \(5(3)^{x+1} = 135\)
    🔗
    Solution.
    Divide both sides by \(5\) to isolate the exponential expression.
    🔗
    \begin{align*} 3^{x+1} \amp = 27 \end{align*}
    🔗
    Since \(27 = 3^3\text{,}\) both sides can be written with the same base.
    🔗
    \begin{align*} 3^{x+1} \amp = 3^3 \end{align*}
    🔗
    When the bases match, the exponents must be equal.
    🔗
    \begin{align*} x + 1 \amp = 3 \end{align*}
    🔗
    \begin{align*} x \amp = 2 \end{align*}
    🔗
    Taking a logarithm of both sides works just as well: \((x+1)\ln(3) = \ln(27)\) gives \(x + 1 = \frac{\ln(27)}{\ln(3)} = 3\text{,}\) so \(x = 2\text{.}\)
    🔗
    🔗
    🔗

    (b)

    \(\log_2(3x + 1) = 4\)
    🔗
    Solution.
    Rewrite the equation in exponential form using \(\log_b(y) = x \iff y = b^x\text{.}\)
    🔗
    \begin{align*} 3x + 1 \amp = 2^4 \end{align*}
    🔗
    \begin{align*} 3x + 1 \amp = 16 \end{align*}
    🔗
    Subtract \(1\) from both sides.
    🔗
    \begin{align*} 3x \amp = 15 \end{align*}
    🔗
    \begin{align*} x \amp = 5 \end{align*}
    🔗
    Check: the argument of the logarithm is \(3(5) + 1 = 16\text{,}\) which is positive, and \(\log_2(16) = 4\) because \(2^4 = 16\text{.}\) The solution is valid.
    🔗
    🔗

    5. Identifying a Pattern from a Table.

    Analyze the data table below. Determine whether the relationship represents a linear, exponential, or quadratic function. If it does not fit any of these, state "None of these."
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(y\) \(3\) \(6\) \(12\) \(24\) \(48\)
    Show your analysis (such as first differences, second differences, or ratios) to justify your conclusion.
    🔗
    Solution.
    The relationship is exponential. Here is the analysis that rules out the other two options.
    🔗
    First differences: \(6 - 3 = 3\text{,}\) \(12 - 6 = 6\text{,}\) \(24 - 12 = 12\text{,}\) and \(48 - 24 = 24\text{.}\) These are not constant, so the table is not linear.
    🔗
    Second differences: \(6 - 3 = 3\text{,}\) \(12 - 6 = 6\text{,}\) and \(24 - 12 = 12\text{.}\) These are not constant either, so the table is not quadratic.
    🔗
    Ratios of consecutive outputs: \(\frac{6}{3} = 2\text{,}\) \(\frac{12}{6} = 2\text{,}\) \(\frac{24}{12} = 2\text{,}\) and \(\frac{48}{24} = 2\text{.}\) Every ratio is the same, and a constant ratio is the defining feature of an exponential function.
    🔗
    The growth factor is \(b = 2\) and the value at \(x = 0\) is \(a = 3\text{,}\) so the function is \(y = 3(2)^x\text{.}\)
    🔗
    🔗
    🔗

    6. An Expanding Rectangle Pattern.

    An expanding rectangle pattern grows from one case to the next. Cases 4 and 5 are shown as empty outlines for you to fill in.
    🔗
    
    Case 1 is a rectangle 1 square wide and 3 squares tall. Case 2 is 2 squares wide and 4 squares tall. Case 3 is 3 squares wide and 5 squares tall. Cases 4 and 5 are drawn as empty dashed rectangles measuring 4 by 6 and 5 by 7.
    🔗
    Case ( \(n\) ) \(0\) \(1\) \(2\) \(3\) \(4\) \(5\)
    Total Squares \(3\) \(8\) \(15\)

    (a)

    Complete the table for Cases 0, 4, and 5. Then analyze the differences in the table to explain why this pattern represents a quadratic relationship.
    🔗
    Solution.
    Each case is a rectangle whose width equals the case number and whose height is two more than the case number. Case 4 is \(4\) by \(6\text{,}\) giving \(24\) squares. Case 5 is \(5\) by \(7\text{,}\) giving \(35\) squares. Case 0 would be \(0\) by \(2\text{,}\) giving \(0\) squares.
    🔗
    Case ( \(n\) ) \(0\) \(1\) \(2\) \(3\) \(4\) \(5\)
    Total Squares \(0\) \(3\) \(8\) \(15\) \(24\) \(35\)
    The first differences are \(3, 5, 7, 9, 11\text{.}\) These are not constant, so the pattern is not linear.
    🔗
    The second differences are \(2, 2, 2, 2\text{.}\) A constant second difference is the signature of a quadratic relationship, which tells us the total number of squares is a quadratic function of the case number.
    🔗
    🔗
    🔗

    (b)

    Find a formula for the total number of squares in Case \(n\text{.}\)
    🔗
    (Hint: look at the dimensions, width and height, of the rectangle in each case and how they relate to the case number \(n\text{.}\))
    🔗
    Solution.
    Reading the dimensions off the pattern: Case 1 is \(1\) by \(3\text{,}\) Case 2 is \(2\) by \(4\text{,}\) and Case 3 is \(3\) by \(5\text{.}\) In every case the width is \(n\) and the height is \(n + 2\text{.}\)
    🔗
    The total number of squares is the area of the rectangle, so
    🔗
    \begin{gather*} T(n) = n(n + 2) = n^2 + 2n \end{gather*}
    🔗
    Check with Case 3: \(T(3) = 3^2 + 2(3) = 9 + 6 = 15\text{,}\) which matches the table. Check with Case 5: \(T(5) = 25 + 10 = 35\text{,}\) which also matches.
    🔗
    Notice that the coefficient of \(n^2\) is \(1\text{,}\) and the constant second difference we found was \(2\text{.}\) This fits the general rule that the second difference of a quadratic equals \(2a\text{.}\)
    🔗
    Alternative method, using the standard form. If you do not spot the dimensions, you can build the formula from the table instead. Start with the general quadratic \(T(n) = an^2 + bn + c\text{.}\)
    🔗
    The constant second difference always equals \(2a\text{.}\) In part (a) the second difference was \(2\text{,}\) so \(2a = 2\) and \(a = 1\text{.}\)
    🔗
    The constant term \(c\) is the output at \(n = 0\text{,}\) which the table gives as \(0\text{,}\) so \(c = 0\text{.}\)
    🔗
    That leaves only \(b\text{.}\) Substitute any known point; using Case 1, where \(T(1) = 3\text{,}\) gives
    🔗
    \begin{align*} 1(1)^2 + b(1) + 0 \amp = 3 \end{align*}
    🔗
    \begin{align*} b \amp = 2 \end{align*}
    🔗
    So \(T(n) = n^2 + 2n\text{,}\) the same formula found from the dimensions. Checking against a different case confirms it: \(T(4) = 16 + 8 = 24\text{,}\) which matches the table.
    🔗
